# «Прораб против волков» — игра Экспертной группы VETA

Браузерный 2D-платформер в фирменном стиле VETA. Технический директор Александр Терентьев в образе прораба
проходит стройку, срывает «овечьи шкуры» с волков — недобросовестных участников строительства — и собирает
документы для суда.

Статус: **прототип для показа руководству** (этапы 1–5 из ТЗ, плюс часть этапа 6). Все тексты — черновики.

---

## Как открыть игру (ничего устанавливать не нужно)

1. Возьмите файл **`dist/index.html`**.
   На GitHub: откройте этот файл и нажмите кнопку «Download raw file» (стрелка вниз справа).
2. Дважды щёлкните по скачанному файлу — игра откроется в браузере.
3. Интернет не нужен: графика, звук, шрифты и код — внутри одного файла (около 1,5 МБ).

Работает в Chrome, Edge, Safari, Firefox, на телефонах (iOS Safari, Android Chrome).
На телефоне держите экран горизонтально — кнопки управления появятся сами.

## Управление

| Действие | Клавиатура | Телефон |
|---|---|---|
| Идти | ← → или A D | кнопки слева |
| Прыжок | Пробел, W или ↑ (держите дольше — прыжок выше) | кнопка «Прыжок» |
| Луч нивелира | X или J | кнопка «Луч» |
| Ходатайство (у босса) | E или Enter | большая красная кнопка |
| Пауза | Esc или P | кнопка в правом верхнем углу |

В меню можно ходить стрелками и нажимать Enter.

## Что проверить глазами (по этапам ТЗ)

**Этап 1. Каркас.** Файл открывается двойным кликом. Титульный экран в синем цвете VETA, угловые рамки:
красные — справа сверху и слева снизу, синие — слева сверху и справа снизу. Кнопка «Играть» ведёт в игру.

**Этап 2. Герой и управление.** Прораб в белой каске, жилете, с планшетом и нивелиром. Бегает, прыгает,
стреляет красным лучом. Прощает мелкие ошибки: можно прыгнуть чуть позже схода с края и нажать прыжок чуть раньше
приземления. Невысокие ступеньки герой проходит сам. На телефоне — экранные кнопки.

**Этап 3. Уровень 1 «Котлован».** Подсказки по ходу. Луч срывает шкуру с волка, прыжок сверху — волк убегает с
табличкой «Претензия принята». Документы появляются в «папке дела» вверху. Ворота суда не пускают, пока в папке
меньше 2 документов этого уровня. Скрытые дефекты проявляются лучом с подписью.

**Этап 4. Уровни 2–3.** «Каркас»: крюки крана, лифт, волки-сметчики, стена из смет «Объём завышен»
(луч её разбирает). «Сдача объекта»: через 40 секунд поднимается вода; если найти лучом течь в трубе — вода уходит.
Наверху спрятан бонусный нотариальный протокол.

**Этап 5. Босс и финал.** Главный волк-генподрядчик со щитом «Заключение-пустышка». Если в папке 7 и больше
документов — появляется кнопка «Ходатайство о повторной экспертизе», щит рассыпается. Если меньше — Терентьев
говорит «Без документов суд нас не услышит…» и возвращает к чекпоинту. Финальный экран: итоги, оценка,
кнопки «Разобрать мой спор», «Поделиться», «Сыграть ещё раз», телефон и сайт.

**Сверх прототипа уже есть:** вступительный комикс, который проигрывается сам (реплики печатаются, у героев
открываются рты), музыка в стиле Денди, карточки «Совет эксперта», звуки, пауза, лёгкий режим,
сохранение прогресса и лучшего счёта (кнопка «Продолжить» на титульном экране).

Полное прохождение — примерно 7–10 минут.

## Как поставить фото Терентьева на героя

1. Положите фото анфас на светлом нейтральном фоне (или PNG с вырезанным прозрачным фоном) в папку
   `assets/source/` под именем **`terentyev.jpg`** (или `terentyev.png`).
2. В папке проекта выполните команду **`npm run sprite`**.
3. Откройте картинку **`assets/sprites/hero_preview.png`** — это крупное превью героя и портрета для диалогов.
   Проверьте, узнаваем ли герой.
4. Если лицо вырезалось неточно, укажите рамку лица вручную (числа — в пикселях фото: левый край, верх, ширина, высота):
   `npm run sprite -- --crop 410,220,380,450`
5. Соберите игру: **`npm run build`**. Новый `dist/index.html` — уже с лицом.

Сейчас в игре уже стоит лицо с присланного фото (файлы `assets/sprites/hero.png` и `hero_portrait.png`).
Если удалить эти два файла, игра сама вернётся к обезличенному «Прорабу» — ничего не ломается.
Отключить портрет можно одной строкой: `USE_PORTRAIT = false` в файле `src/config.js`.

## Что можно поменять без программиста

| Что | Где |
|---|---|
| Все тексты игры (реплики, советы, подсказки, финал) | `content/ru.json` — у каждого текста поле `"status": "draft"`; после согласования поменяйте на `"approved"` |
| Ссылка кнопки «Разобрать мой спор», телефон, сайт, ссылка «Поделиться» | `src/config.js` |
| Баланс: число касок, сколько документов нужно воротам и боссу, скорость воды | `src/config.js`, раздел `BALANCE` |
| Логотип | положите официальный файл в `assets/brand/logo.svg` (или `logo.png`) и соберите игру |
| Цвета | `src/palette.js` |
| Шрифт | `src/brand.js` (строка `FONT_MAIN`) и `src/fonts.js` |

После любых правок выполните `npm run build`.

## Для того, кто будет собирать (один раз на компьютер)

1. Установите **Node.js** версии 20 или новее: https://nodejs.org (кнопка LTS).
2. Для команды со спрайтом из фото — **Python 3** (https://python.org) и библиотеку Pillow: `pip install pillow`.
3. Откройте папку проекта в терминале и выполните `npm install` (скачает Phaser и инструменты сборки).

Команды:

| Команда | Что делает |
|---|---|
| `npm run dev` | запускает игру для разработки, адрес появится в окне (обновляется сама при правках) |
| `npm run build` | собирает один файл `dist/index.html` |
| `npm run sprite` | делает спрайт героя и портрет из фото `assets/source/terentyev.jpg` |

## Где что лежит

```
SPEC.md          — техническое задание
README.md        — эта инструкция
DECISIONS.md     — решения, принятые по ходу, и заглушки
CREDITS.md       — источники и лицензии
content/ru.json  — все тексты
src/config.js    — настройки: портрет, ссылка CTA, контакты, баланс
src/palette.js   — фирменные цвета
src/brand.js     — шрифты и угловые рамки (CornerFrame)
src/scenes/      — экраны: загрузка, титул, «как играть», комикс, уровень, советы, пауза, финал
src/objects/     — герой, волки, овцы, босс, документы, дефекты, чекпоинты, ворота суда, платформы
src/levels/      — карты трёх уровней
src/ui/          — HUD, кнопки, экранное управление, реплики
src/audio/       — звуки (генерируются кодом)
src/gfx/         — пиксель-арт (рисуется кодом)
tools/           — скрипт спрайта из фото
assets/source/   — исходное фото (в сборку и репозиторий не попадает)
assets/sprites/  — шаблон тела героя и готовый спрайт из фото
assets/brand/    — официальный логотип и шрифты по лицензии
dist/index.html  — готовая игра
```

## Режим проверки (для разработчика)

Если открыть игру с `?debug` в адресе (`index.html?debug`), появляется счётчик FPS и клавиши:
**K** — положить в папку все документы до текущего уровня, **L** — завершить уровень,
**T** — перенестись к арене босса / концу уровня. `?debug&level=3` — сразу начать с уровня 3.
В обычной игре этих возможностей нет.
