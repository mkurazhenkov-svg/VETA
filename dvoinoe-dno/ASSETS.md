# Ассеты

Сейчас в игре нет ни одного растрового ассета: фоны, предметы, люди, портреты, фотопластинки и звук
синтезируются кодом (src/scene/painter.ts, src/scene/people.ts, src/scene/photo-render.ts, src/audio/sound.ts)
из данных content/. Это плейсхолдеры «в живописной манере» до прихода художника (этап M8).

| Ассет | Источник | Права |
| --- | --- | --- |
| Фоны 7 локаций, предметы | процедурно из scene.json | собственные |
| Фигуры и портреты 20 персонажей | процедурно (people.ts) из case.yaml | собственные |
| Фотопластинки, крупные планы улик | процедурно (photo-render.ts) | собственные |
| Изображения кредитных билетов | стилизованный условный рисунок «25», серия вымышлена | игровой реквизит |
| Звук | синтез Web Audio | собственные |
| Музыка (3 пьесы: вальс-романс, романс, наигрыш гармони) | собственные мелодии в духе эпохи, синтез Web Audio (src/audio/music.ts) | собственные |
| Шрифты | см. THIRD_PARTY.md | OFL |

Фото экспонатов и архивные материалы — только с правами музея и архивов (поле `photo` в content/museum/exhibits.yaml).
