# Двойное дно. Дело о фальшивых четвертных

Изометрический диалоговый квест музея фальшивых денег и подделок «Двойное дно» (Нижний Новгород) и кафедры судебной
экспертизы. Игрок — судебный следователь: август 1913 года, ярмарка, подвал фальшивомонетчиков на Миллионке.

**Как открыть:** `dist/index.html` — двойной клик, интернет не нужен (всё в одном файле).

- «Экспозиция» (20–25 мин): музей → подвал → сличение в кассе Госбанка. Подсказки, без баллов.
- «Практикум» (60–90 мин): 7 локаций, понятые, 12 пластинок, протокол, экспертиза, телеграмма, 100-балльная оценка и разбор.
- `?mode=teacher` — преподаватель (PIN 1864): вариант истины, лимиты, «без случайности», журналы студентов.
- `?kiosk=1` — киоск музея: заставка, автосброс, сервисное меню.
