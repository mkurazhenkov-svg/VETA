## Отклонения от ТЗ

- **PDF** — через «Печать → Сохранить как PDF» со стилями печати, а не pdfmake: так дореформенная орфография и шрифты
  выходят без искажений и без лишних 2 МБ в сборке.
- **Навигация** — A* по мелкой сетке (0,2 аршина) со сглаживанием пути вместо полигонального навмеша; редактор правит те же полигоны.
- **Сборка** — один файл `dist/index.html` (≈1,6 МБ, всё внутри, открывается двойным кликом), рядом `sw.js` и манифест для киоска.
- **CSS** — один файл стилей вместо CSS Modules.
- **Tauri** не делался (PWA в полноэкранном режиме закрывает задачу киоска).
- **Сцена** хранит координаты в аршинах мира, а не в пикселях фона: измерения и план считаются точно, проекция — одна формула.

## Известные проблемы

- Арт процедурный; лица и фигуры — стилизация, а не живопись художника.
- В «Экспозиции» нет озвучки (этап 2 по ТЗ).
- Английской локализации нет (строки вынесены в `content/i18n/ru.yaml`, но не все тексты интерфейса переведены на ключи).
- Карточки «1913 → сегодня», статьи Устава, маршруты экспертизы и признаки билетов — черновики до проверки (docs/OPEN_QUESTIONS.md).

## Как проверить приёмку руками

```bash
pnpm install
pnpm lint && pnpm test && pnpm validate && pnpm build
pnpm e2e        # 5 сценариев, скриншоты в docs/screenshots
pnpm dev        # http://localhost:5173/ , ?mode=exhibit , ?mode=teacher , ?kiosk=1 , ?editor
```
