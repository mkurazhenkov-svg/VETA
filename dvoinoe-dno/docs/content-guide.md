# Как править контент (для музея и кафедры)

Весь учебный и музейный контент — текстовые файлы в папке `content/`. Программист не нужен:
поправьте файл, выполните `pnpm validate` (проверка) и `pnpm build` (сборка). Если в файле ошибка —
проверка напишет, в каком файле и какой строке.

## Где что лежит

| Что | Файл |
| --- | --- |
| Фабула, локации, персонажи, варианты истины, события по часам, телеграмма, экспертиза | `content/cases/chetvertnye-1913/case.yaml` |
| Улики: описание, строка протокола, как изымать, что даёт | `.../evidence.yaml` |
| Факты записной книжки | `.../facts.yaml` |
| Картотека версий | `.../theories.yaml` |
| Диалоги | `.../ink/*.ink` (язык Ink, см. ниже) |
| Архивные документы (дореформенная орфография) | `.../documents/*.md` |
| Сцены: стены, предметы, хотспоты, сектора | `.../scenes/<локация>/scene.json` (удобнее — в редакторе `?editor`) |
| Правила 1913 г., штрафы, веса, слова-выводы, PIN преподавателя | `content/rules/rules.yaml` |
| Способы изъятия и упаковки | `content/rules/packaging.yaml` |
| Голоса и архетипы | `content/rules/skills.yaml` |
| Техника 1913 и сегодня | `content/rules/tools.yaml` |
| Карточки «1913 → сегодня» | `content/rules/bridge-today.yaml` |
| Экспонаты-двойники, промо, киоск | `content/museum/exhibits.yaml` |
| QR-коды витрин | `content/museum/qr.yaml` |
| Надписи интерфейса | `content/i18n/ru.yaml` |

## Пример: сотрудник музея меняет текст карточки экспоната

1. Откройте `content/museum/exhibits.yaml`.
2. Найдите `id: ex_press`, поменяйте `text:` и, если экспонат подтверждён, `confirmed: true`.
3. `pnpm validate && pnpm build` — в игре после осмотра пресса появится обновлённая карточка «Это есть в музее».

## Пример: кафедра вписывает статью Устава

В `content/rules/rules.yaml` у правила замените `source1913: "TODO(кафедра) …"` на текст ссылки. Он появится в карточке
нарушения в разборе.

## Диалоги на Ink — соглашения

```ink
=== mitrofan ===
Дворник Митрофан мнёт шапку. #s:mitrofan #m:tense          // реплика персонажа и настроение портрета
Чутьё: Пригрозите — и всё выложит. #v:instinct #shortcut    // голос в голове (короткий путь)
Логика: Подковки у половины мужиков. #v:logic #p:7          // пассивная проверка: видна, если навык + 6 ≥ 7
+ [Расскажи, что видел ночью. #open]                        // теги реплик: open, clarify, control, leading, pressure, threat, present
    ~ fact("f_dvornik_two_men")                             // записать факт (id из facts.yaml)
+ [Наблюдательность — присмотреться #check:observ:9:rep:k_boots]   // проверка 2д6; результат — в переменной last_check
    {last_check: Подковка! | Ничего не видно.}
```

Внешние функции: `fact`, `has`, `skill`, `variant` (main/landlord/guest), `trust`, `add_trust`, `spend`, `set_flag`, `flag`,
`mode`, `examined`, `collected`, `condition`, `clock`, `invite`, `dismiss`, `is_witness`, `witnesses_count`, `ui`.

## Арт художника

Положите `base.webp` (основная живопись, размер холста — поле `canvas` в scene.json) и при необходимости `hidden.webp`
(следы, видимые только в круге лампы) в папку сцены — игра возьмёт их вместо плейсхолдера. Раскладка и подмалёвок —
`pnpm placeholder-art` → `docs/art-reference/`.
